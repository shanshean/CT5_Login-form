# Simple Python Login Form (Tkinter GUI)
 
This is a basic graphical login interface built using Python’s built‑in Tkinter library. It accepts a username and password, then checks whether the credentials match the hard‑coded values ( admin  /  12345 ). It will pop‑up a message box for either successful login or failed login. The design uses a custom green‑gold color theme.
 
Python 3.x
Tkinter (usually pre‑installed with Python; no extra installation needed)
